# Chat Longshot

Chat Longshot 是一个面向 AI 对话网页的 Edge / Chrome 长截图扩展。它可以在 ChatGPT、Gemini、DeepSeek、Grok、豆包等网页中选择对话范围，按网页原样自动滚动截图、拼接成长图，并导出为 JPG；当截图被拆成多张 JPG 时，也可以选择合成为 PDF。

[English README](./README.en.md)

## 功能

- 支持 Microsoft Edge 和 Google Chrome 的 Manifest V3 扩展加载方式。
- 支持 ChatGPT、Gemini、DeepSeek、Grok、豆包等常见 AI 对话网页。
- 点击扩展图标后直接进入范围选择模式。
- 候选点按对话块生成，支持任意选择一个或两个点。
- 选择两个点时，自动按页面位置判断截图起点和终点。
- 选择第三个点时，优先固定已确定的起点，只调整终点；如果新点更靠上，则更新起点。
- 截图前自动跳转到截图起点。
- 自动滚动、分段截图、Canvas 拼接。
- 默认导出 JPG，超长结果会自动拆成多张 JPG。
- 多张 JPG 可选合成为 PDF，合成后会静默尝试清理临时 JPG。
- 截图时会尽量隐藏侧栏、输入框、导航栏等无关页面元素。

## 本地安装

### Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目目录。
5. 打开支持的 AI 对话网页，点击浏览器工具栏里的 Chat Longshot 图标。

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 打开支持的 AI 对话网页，点击浏览器工具栏里的 Chat Longshot 图标。

## 使用方式

1. 打开一个 AI 对话网页。
2. 点击浏览器工具栏里的 Chat Longshot。
3. 在正文左侧候选点中选择一个或两个对话点。
4. 点击底部工具栏的“截图”。
5. 截图期间不要手动滚动页面。
6. 如果生成了多张 JPG，可以选择是否合成为 PDF。

## 隐私说明

扩展只在本地读取当前标签页的视觉渲染结果并生成图片文件，不上传对话内容，不调用任何 AI 平台 API，也不保存聊天文本。
